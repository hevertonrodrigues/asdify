Дайте своему ИИ-агенту повторяемую процедуру редактирования: найти главное, убрать лишнее и проверить, что важные детали сохранились. ASDify — небольшой переносимый навык в Markdown для ответов, переводов, сообщений о ходе работы, отчётов и документации в поддерживаемых агентах для программирования и редакторах.

## Пример редактирования

**До**

> Мы хотели бы подчеркнуть, что, по предварительным данным, выручка от подписок в Бразилии выросла на 12% по сравнению с аналогичным периодом прошлого года, без учёта возвратов. Эти данные ещё не прошли аудит.

**После (`full`)**

> По предварительным данным, выручка от подписок в Бразилии выросла на 12% по сравнению с аналогичным периодом прошлого года, без учёта возвратов. Эти данные ещё не прошли аудит.

*Это редакторский пример, а не измеренный результат работы модели.* Сохранены предварительный характер данных, подписки, Бразилия, 12%, годовой период сравнения, исключение возвратов и отсутствие аудита. [Другие примеры до и после](examples/before-after.md).

## Попробовать без установки

1. Откройте [SKILL.md](skills/asdify/SKILL.md), скопируйте содержимое и вставьте его как инструкции в чат, например ChatGPT или веб-версию Claude. Канонический навык написан на английском.
2. Отправьте этот запрос:

```text
Используйте asdify full. Перепишите это сообщение для руководства.
Верните только отредактированный текст. Сохраните все факты и оговорки.

Мы хотели бы подчеркнуть, что, по предварительным данным, выручка
от подписок в Бразилии выросла на 12% по сравнению с аналогичным периодом
прошлого года, без учёта возвратов. Эти данные ещё не прошли аудит.
```

Формулировки могут отличаться, но факты и оговорки должны сохраниться. Это ручная проба без автоматической установки навыка. В [реальном запуске Codex](docs/demos/codex-full-2026-10-08.md) приведены запрос, ответ и проверка сохранённых деталей на английском.

## Установить для своего агента

Сам ASDify не требует Node.js или npm. Необязательная Skills CLI может запросить подтверждение перед загрузкой своего npm-пакета. Используйте [локальный установщик](INSTALL.md#local-installer), чтобы избежать этой загрузки; см. также [установку нативного навыка Cursor без npm](INSTALL.md#cursor-without-nodejs-or-npm).

Используйте [Skills CLI](https://github.com/vercel-labs/skills), чтобы найти и установить ASDify:

```bash
npx skills add hevertonrodrigues/asdify --list
npx skills add hevertonrodrigues/asdify --skill asdify --agent claude-code
```

Замените `claude-code` на [ID своего агента](docs/HARNESSES.md), например `codex`, `cursor`, `gemini-cli` или `opencode`. Запускайте из целевого проекта; добавьте `--global` для установки на уровне пользователя, если это поддерживается. Области установки, пути и удаление описаны в [руководстве](INSTALL.md).

Если предпочитаете локальный установщик:

```bash
git clone https://github.com/hevertonrodrigues/asdify.git
cd asdify
bash scripts/install.sh --list
bash scripts/install.sh --agent claude-code --scope user
```

Выберите ID из `--list`. Установщик копирует полный навык и справочные материалы из клона без загрузок. Он отказывается перезаписывать существующие файлы без `--force`.

Для нативных навыков Cursor локальный ID — `cursor-skill`; `cursor` сохраняет прежний адаптер кратких правил проекта. Skills CLI использует `cursor` для нативных навыков. [Различия и пути](INSTALL.md#cursor-native-skill-or-compact-rule).

[Таблица агентов](docs/HARNESSES.md) охватывает реестр этой версии. Проверки установки и реальные сеансы отдельно отмечаются в разделе [совместимости](docs/COMPATIBILITY.md). Для других агентов используйте путь, указанный в их документации, или ручную пробу выше.

## Как редактирует ASDify

Определите читателя, выделите обязательные детали, внесите минимальное полезное изменение и проверьте смысл. Сохраняйте числа, даты, условия, неопределённость и необходимые технические термины. Уже понятный текст оставляйте без изменений. При переписывании не придумывайте советы, решения или сроки.

| Режим | Когда использовать | Что меняется |
| --- | --- | --- |
| `lite` | Нужна лёгкая правка | Формулировки; структура, порядок и тон сохраняются. |
| `full` · по умолчанию | Нужен более понятный ответ | Формулировки и структура, когда это полезно. |
| `ultra` | Есть лишние вступления или разделы | Более сильное сокращение с теми же правилами сохранения смысла. |

Запросите режим через `Используйте asdify lite`, `full` или `ultra`. `asdify off` отключает эту необязательную процедуру с учётом остальных инструкций агента. Режимы — это инструкции; поддержка нативных команд зависит от продукта.

## Языки и перевод

README и регрессионные примеры доступны на английском, бразильском португальском, испанском, французском, немецком, японском, упрощённом китайском, итальянском и русском. Для всех языков устанавливается один канонический навык; языковые пакеты не нужны. При переписывании сохраняется язык оригинала, если перевод не запрошен.

```text
Используйте asdify full. Переведите на русский (ru).
Верните только перевод. Сохраните все факты и оговорки.

Preliminary subscription revenue grew 12% year over year in Brazil,
excluding refunds. These figures are unaudited.
```

Укажите целевой язык или его региональный вариант. Перевод сохраняет смысл, идентификаторы, заполнители и требуемый формат, адаптируя грамматику и стиль. См. [многоязычные примеры](examples/multilingual.md) и [языковое покрытие и поддержку](docs/LANGUAGES.md). Качество зависит от модели агента; тесты пакета его не проверяют.

| Задача | Что сохранить | Полный запрос |

| Техническая рекомендация | Идентификаторы, исполнитель, порядок и отличие рекомендации от обязанности | [`lite` · PT-BR](examples/recipes.md#2-technical-recommendation-pt-br) |

## Проверка и поддержка

Более короткий ответ, изменивший существенный факт, не проходит оценку. Репозиторий содержит примеры переписывания и перевода на девяти языках, критерии оценки человеком и [воспроизводимый протокол](benchmarks/README.md). **Улучшение качества на реальных моделях пока не доказано.** См. [проверку пакета](docs/VERIFICATION.md) и [совместимость](docs/COMPATIBILITY.md).

Пропало условие, изменилось число или появилось выдуманное обещание? Ошибки в этом README можно сообщить через [форму перевода документации](https://github.com/hevertonrodrigues/asdify/issues/new?template=documentation_translation.yml). Порядок участия описан в [CONTRIBUTING.md](CONTRIBUTING.md).
