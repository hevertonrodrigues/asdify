# Security Policy

This repository contains written agent instructions and an optional local installer. Treat them as code: review changes before running or copying them into a trusted environment.

Supported: latest tagged release and `main`.

**Do not file public issues containing credentials or private data.** Use [GitHub private vulnerability reporting](https://github.com/hevertonrodrigues/asdify/security), enabled for this repository. Include the affected version, reproduction steps, and expected behavior without exposing real credentials.

The local Bash installer does not collect telemetry, require API tokens, or contact remote services. It copies local files only. The optional external Skills CLI has its own network and telemetry behavior, described in [INSTALL.md](INSTALL.md).
