# Security Policy

This repository contains written agent instructions and an optional local installer. Treat them as code: review changes before running or copying them into a trusted environment.

Supported: latest tagged release and `main` during pre-release development.

**Do not file public issues containing credentials or private data.** Once the repository is published, use GitHub's private vulnerability reporting feature (if enabled) or privately contact the maintainers through the profile's published contact method. Until a private channel is configured, avoid sharing exploit details publicly.

The project does not collect telemetry, require API tokens, or contact remote services during installation. The script copies local files only.
