# README visuals

Original, hand-authored SVG artwork for ASDify. These files are covered by the repository’s [MIT license](../../LICENSE).

The English and Brazilian Portuguese variants use local vector shapes and system-font fallbacks. They contain no external resources, scripts, or embedded raster images. Each SVG includes a title and description for accessibility; the README also provides text alternatives and a copyable example.

The before/after example is illustrative. It is not a benchmark result or measured performance claim.
