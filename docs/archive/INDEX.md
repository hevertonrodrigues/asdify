# Project archive

Development notes, research, and the original package are preserved here for reference. To try ASDify, start with the [main README](../../README.md). For current checks, see [verification](../VERIFICATION.md).

| Material | Contents |
| --- | --- |
| [Source notes](quality/SOURCES_AND_ATTRIBUTION.md) | Conceptual references and attribution |
| [Repository review](strategy/GITHUB_REPOSITORY_REVIEW.md) | Reference-project research and adoption decisions |
| `strategy/` | Earlier product plans and handoff notes |
| `history/` | Original requests and an annotated conversation reconstruction |
| [Original package](original-release/README.md) | Unchanged draft ZIP, including its historical names |
| `quality/` | Dated test reports and research snapshots |
| `PACKAGE_METADATA.json` | Local package snapshot; not a live publication or quality signal |
| `SOURCE_MANIFEST.sha256` | Checksums at this repository revision, with paths relative to the repository root |

The history is not an official conversation export. Quoted messages, earlier plans, and archive contents can contain former names and paths. Historical test reports describe their own runs; they do not establish present host compatibility or live-model quality.

The source manifest excludes itself, Git metadata, local environment files, and generated caches. After changing source files, regenerate it before treating it as a current integrity snapshot.
