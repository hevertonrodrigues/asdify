# Known limitations and status

**Repository candidate, not a production-proven skill.**

- The complete editable draft is packaged and has tests for structural validation and installer behavior.
- The skill has not been evaluated through a completed blinded A/B experiment with live language models. The fixtures are proposed test cases, not performance results.
- GitHub availability for the proposed owner/name, package names, and domains was not verified in this packaging step.
- Commands and installation behavior can differ across agent hosts and software versions. Review each platform's current official documentation before broad compatibility claims.
- ASD-STE100 is an English controlled-language specification. ASDify generalizes selected **principles** to different languages and domains. It is not certified, compliant, affiliated with, or endorsed by ASD.
- The transcript comes from the user's own text, not a verified audiovisual transcription.
- The conversation history is a curated reconstruction with verbatim user inputs and detailed summaries of assistant replies. It is **not** an official complete chat export.
- The included original repository ZIP is preserved unchanged. Any work completed after this packaging date is not included automatically.
- The proposed GitHub SEO/discovery strategy is not a guarantee of ranking or popularity.
